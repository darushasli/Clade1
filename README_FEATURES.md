# 🤖 ربات سین‌زن خودکار تلگرام

ربات تلگرام برای افزایش خودکار تعداد سین (views) پست‌های کانال‌ها.

## ✨ ویژگی‌ها

- ➕ افزودن/حذف کانال‌ها
- 🔢 تنظیم تعداد سین برای هر کانال
- ⚙️ تنظیم سین پیش‌فرض
- 🔧 مدیریت پروکسی
- 📋 نمایش لیست کانال‌ها و پروکسی‌ها
- 🔄 خطا دهی خودکار با retry
- 📝 لاگ پیشرفته

## 📋 پیش‌نیازها

- Python 3.8+
- pip3
- اتصال به اینترنت
- توکن ربات تلگرام

## 🚀 راه‌اندازی سریع

### 1. دانلود فایل‌ها
```bash
# کل پوشه را دانلود کنید
unzip telegram_bot.zip
cd telegram_bot
```

### 2. نصب خودکار (توصیه می‌شود)
```bash
chmod +x setup.sh
./setup.sh
```

### 3. نصب دستی (اگر setup.sh کار نکرد)
```bash
# ایجاد محیط مجازی
python3 -m venv venv

# فعال‌سازی محیط مجازی
# در Linux/Mac:
source venv/bin/activate
# در Windows:
venv\Scripts\activate

# نصب کتابخانه‌ها
pip install -r requirements.txt
```

## ⚙️ تنظیم توکن

### راه 1: توسط setup.sh (خودکار)
setup.sh خود درخواست می‌کند

### راه 2: دستی

1. **دریافت توکن از @BotFather**:
   - Telegram را باز کنید
   - @BotFather را سرچ کنید
   - /newbot را ارسال کنید
   - نام ربات را وارد کنید (مثلاً: "My View Bot")
   - نام کاربری را وارد کنید (باید `_bot` پایانی داشته باشد)
   - توکن را کپی کنید

2. **تنظیم توکن**:
   - فایل `.env` را باز کنید
   - `TELEGRAM_BOT_TOKEN=` بعد توکن را قرار دهید
   - ذخیره کنید

**مثال:**
```
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstu-VWXyZ1234567890
```

## ▶️ اجرای ربات

```bash
# فعال‌سازی محیط مجازی (اگر قبلاً فعال نیست)
source venv/bin/activate

# اجرای ربات
python3 telegram_view_bot.py
```

## 🎯 نحوه استفاده

1. **ربات را شروع کنید**: `/start` را به ربات بفرستید
2. **دکمه‌ها را فشار دهید**:
   - ➕ **افزودن کانال**: نام یا @username کانال را وارد کنید
   - 📋 **لیست کانال‌ها**: تمام کانال‌های ثبت‌شده را ببینید
   - ❌ **حذف کانال**: یک کانال را حذف کنید
   - ⚙️ **تنظیم سین پیش‌فرض**: سین پیش‌فرض را مشخص کنید
   - 🔢 **تنظیم سین برای کانال**: سین برای یک کانال خاص را تنظیم کنید
   - 🔧 **مدیریت پروکسی**: پروکسی‌ها را اضافه/حذف کنید

## 🐛 حل‌مسائل

### خطا: "AttributeError: 'NoneType' object has no attribute 'message_handler'"
✅ **حل شده در نسخه جدید** - handlers اکنون بعد از مقدار دهی ربات ثبت می‌شوند

### خطا: "TELEGRAM_BOT_TOKEN تنظیم نشده"
1. `.env` را بررسی کنید
2. توکن را صحیح وارد کنید (فاصله ندارد)
3. ربات را دوباره اجرا کنید

### خطا: "Could not find a version that satisfies the requirement"
```bash
# لیست کتابخانه‌ها را به‌روز کنید
pip install --upgrade pip
pip install -r requirements.txt
```

### خطا: "ModuleNotFoundError"
```bash
# محیط مجازی را فعال کنید
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate      # Windows
```

### ربات کنار نمی‌رود
```bash
# دستی متوقف کنید
Ctrl+C

# یا در پس‌زمینه کنید
nohup python3 telegram_view_bot.py > bot.log 2>&1 &
```
