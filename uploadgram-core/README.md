# افزونه UploadGram Core

هسته‌ی فروشگاه آپلودگرام: اتصال خدمات به API، کیف پول و پنل کاربری **بدون سبد خرید**.

---

## 🧩 این افزونه چه می‌کند؟

- به هر محصول ووکامرس یک تب **«سرویس آپلودگرام»** اضافه می‌کند تا مشخص کنی به کدام API وصل شود (فالوران / نامبرلند / ربات تلگرام).
- **سبد خرید را غیرفعال** می‌کند؛ هر سفارش **آنی** ثبت و از **کیف پول** کسر می‌شود.
- سفارش را خودکار به API درست می‌فرستد، وضعیت را هر ۲ دقیقه همگام می‌کند، و در صورت شکست **وجه را خودکار برمی‌گرداند**.
- برای شماره مجازی، **کد OTP** را زنده در پنل نمایش می‌دهد.
- پنل کاربری با شورت‌کد: کیف پول، فرم سفارش، سفارش‌های من.

---

## ⚙️ پیش‌نیازها (به ترتیب نصب)

1. **WooCommerce** — مدیریت محصول، حساب کاربری، سفارش
2. **TeraWallet** (نام قدیم WooWallet) — کیف پول و شارژ
3. یک **درگاه پرداخت ایرانی** (زرین‌پال، آی‌دی‌پی و…) — فقط برای شارژ کیف پول
4. همین افزونه: **UploadGram Core**

---

## 📦 نصب

1. پوشه `uploadgram-core` را در `wp-content/plugins/` بگذار (یا ZIP را از **افزونه‌ها ← افزودن ← بارگذاری** نصب کن).
2. **فعال** کن. (جدول سفارش‌ها و کران خودکار ساخته می‌شود.)
3. برو **پیشخوان ← آپلودگرام** و کلیدهای API را وارد کن.

---

## 🔑 تنظیم API (منوی «آپلودگرام»)

| تب | چه چیزی وارد کنی |
|----|------------------|
| **عمومی** | واحد پول، نرخ دلار (برای فالوران)، درصد سود |
| **فالوران** | آدرس API (`https://my.followeran.ir/api/v2`) + کلید API |
| **نامبرلند** | آدرس API + کلید API |
| **ربات تلگرام** | آدرس وب‌هوک ربات + توکن امنیتی |
| **ابزار و تست** | دکمه تست اتصال هر سرویس |

> بعد از وارد کردن کلیدها، از تب **«ابزار و تست»** اتصال هر سرویس را چک کن.

---

## 🛍️ تنظیم هر محصول

هنگام ساخت/ویرایش محصول، تب **«سرویس آپلودگرام»**:

- **سرویس اتصال**: فالوران / نامبرلند / ربات تلگرام / بدون اتصال (دستی)
- **شناسه سرویس (Service ID)**: شناسه سرویس در سمت API
  - نامبرلند: می‌تونی `service:country` بذاری (مثلاً `1:0`)
- **ورودی کاربر**: لینک / یوزرنیم / بدون ورودی (شماره و اکانت)
- **حداقل/حداکثر تعداد**
- **قیمت ثابت؟**: برای شماره/اکانت تیک بزن
- **نرخ هر ۱۰۰۰**: برای خدمات تعدادی (قیمت = تعداد ÷ ۱۰۰۰ × نرخ)

---

## 🧾 ساخت پنل کاربری (شورت‌کدها)

یک صفحه بساز و بذار:

| شورت‌کد | کارش |
|---------|------|
| `[ug_panel]` | داشبورد کامل (کیف پول + سفارش‌ها) |
| `[ug_wallet]` | فقط کیف پول + دکمه شارژ |
| `[ug_my_orders]` | تاریخچه سفارش‌ها + نمایش زنده کد OTP |
| `[ug_order_form id="123"]` | فرم سفارش آنی یک محصول (در صفحه محصول `id` لازم نیست) |

مثال: در صفحه‌ی هر خدمت، `[ug_order_form]` را بگذار تا فرم سفارش آنی نمایش داده شود.

---

## 🔄 نگاشت بخش‌ها به API

| بخش | سرویس | نکته |
|-----|-------|------|
| ممبر آپلودی تلگرام | ربات خودتان | قرارداد JSON در `class-ug-provider-telegram.php` تعریف شده |
| ممبر/فالوور/ویو/لایک | فالوران | API استاندارد SMM (`action=add`) |
| شماره مجازی + اکانت | نامبرلند | خرید شماره + دریافت OTP |

> ⚠️ **مهم:** فرمت دقیق پارامترهای فالوران/نامبرلند در فایل‌های `providers/` در یک نقطه متمرکز شده. اگر مستندات رسمی نام پارامتر متفاوتی داشت، فقط همان‌جا اصلاح کن (با کامنت مشخص شده). بعد از گرفتن مستندات، این‌ها را نهایی می‌کنیم.

---

## 🤖 قرارداد ربات تلگرام

سایت این JSON را به وب‌هوک ربات POST می‌کند:

```json
POST {آدرس وب‌هوک}
Authorization: Bearer {توکن}
{ "action": "add_members", "service": "...", "target": "@channel", "quantity": 500 }
```

ربات باید پاسخ دهد:
```json
{ "ok": true, "order_id": "BOT-123", "status": "processing" }
```

و برای استعلام وضعیت:
```json
{ "action": "status", "order_id": "BOT-123" }  →  { "ok": true, "status": "completed" }
```
