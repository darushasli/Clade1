# پل ربات تلگرام — `ug-bridge.php`

این فایل، سایت وردپرسی آپلودگرام را به **ربات آپلودر تلگرام** (که روی هاست جدا
اجرا می‌شود) وصل می‌کند تا سفارش‌های «ممبر تلگرام» مستقیم و با فرمت درست در
دیتابیس ربات ثبت شوند.

## نصب (روی هاست ربات)

1. فایل `ug-bridge.php` را در پوشهٔ ربات (کنار `config.php`) آپلود کنید.
   مثلاً اگر ربات در `https://activemember.shop/6/` است:
   `https://activemember.shop/6/ug-bridge.php`
2. داخل فایل، مقدار `UG_BRIDGE_SECRET` را به یک رشتهٔ **تصادفی و طولانی** تغییر دهید:
   ```php
   define( 'UG_BRIDGE_SECRET', 'یک‌رشتهٔ‌تصادفی‌مثلاً‌۴۰‌کاراکتری' );
   ```
   برای ساختن یک secret خوب می‌توانید در ترمینال بزنید:
   ```bash
   php -r "echo bin2hex(random_bytes(24));"
   ```

## تنظیم در وردپرس

پیشخوان › **آپلودگرام › ربات تلگرام**:

| فیلد | مقدار |
|------|-------|
| آدرس وب‌هوک ربات | آدرس کامل `ug-bridge.php` (مثلاً بالا) |
| توکن امنیتی | **همان** مقدار `UG_BRIDGE_SECRET` |

سپس در تب **ابزار و تست**، دکمهٔ «تست ربات» را بزنید؛ اگر درست باشد قیمت‌ها و
یوزرنیم ربات را برمی‌گرداند.

## چطور کار می‌کند

```
سایت (کیف پول وردپرس)                 ug-bridge.php (هاست ربات)
─────────────────────                 ─────────────────────────
۱) quote   ── قیمت + انتخاب ربات + ربات بررسی ──▶
۲) کاربر ربات بررسی را ادمین کانالش می‌کند
۳) پرداخت از کیف پول سایت
۴) check   ── آیا ربات ادمین شد؟ ──▶  (اجباری)
۵) create  ── ثبت در orders با status='processing' ──▶
                                       processor.php برمی‌دارد → ممبرگیری
۶) status  ── پیگیری تا completed ──▶
```

## اندپوینت‌ها (همه POST، بدنهٔ JSON، همراه `secret`)

| action | ورودی | خروجی |
|--------|-------|-------|
| `ping` | — | `{ok, price_ethical, price_unethical, min, max, bot_username}` |
| `quote` | `order_type`, `count` | `{ok, price, price_per_1000, assigned_bot, check_bot}` |
| `check` | `assigned_bot`, `channel` | `{ok, is_admin}` |
| `create` | `channel`, `count`, `order_type`, `assigned_bot`, `web_user_id?` | `{ok, order_id, status, price}` یا `{ok:false, error:'membership_not_verified'}` |
| `status` | `order_id` | `{ok, status, result, current_count, target_count}` |
| `cancel` | `order_id` | `{ok, status}` |

## امنیت

- پرداخت فقط در سایت انجام می‌شود؛ پل کیف‌پول ربات را دور می‌زند و سفارش
  از-پیش-پرداخت‌شده را وارد صف می‌کند.
- بدون `secret` درست، هر درخواست ۴۰۱ می‌گیرد.
- قیمت همیشه **سمت سرور** (روی هاست ربات) دوباره محاسبه می‌شود؛ به قیمت
  ارسالی از کلاینت اعتماد نمی‌شود.
- ⚠️ چون توکن‌ها در نسخهٔ اشتراکی لو رفتند: توکن ۵ ربات آپلودر، `BOT6_TOKEN` و
  `FJ_API_SECRET` را عوض کنید.
