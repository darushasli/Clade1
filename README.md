# 🤖 Telegram Bot Pro v4.0

رباتی تمیز و پایدار برای **مدیریت فهرست کانال‌ها و پروکسی‌ها** روی تلگرام،
ساخته‌شده با `python-telegram-bot` و دیتابیس امنِ SQLite.

> این ربات یک ابزار مدیریت داده است: کانال‌ها و پروکسی‌ها را ذخیره، فهرست و حذف
> می‌کند. اگر پروکسی‌ای ثبت شده باشد، **اتصال خودِ ربات به تلگرام** از آن عبور
> می‌کند (مفید در شبکه‌های محدود).

---

## ✨ ویژگی‌ها

- 📋 مدیریت کانال‌ها: افزودن، فهرست، حذف
- 🔧 مدیریت پروکسی‌ها: افزودن، فهرست، حذف
- 🌐 مسیریابی اتصال ربات از طریق اولین پروکسی ثبت‌شده
- 🛡️ دیتابیس Thread-safe با مدیریت خطای کامل
- 🧭 صفحه‌بندی برای فهرست‌های بلند (بدون محدودیت ۱۰۰ دکمه)
- ✅ اعتبارسنجی ورودی برای نام کانال و آدرس پروکسی
- 📝 لاگ چرخشی (تا دیسک پر نشود)
- 🔒 فقط چت خصوصی (در گروه‌ها پاسخ نمی‌دهد)

---

## 📋 نیازمندی‌ها

- Python **3.8+**
- یک توکن ربات از [@BotFather](https://t.me/BotFather)

## 🚀 نصب و راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها
bash SETUP.sh            # یا: pip install -r requirements.txt

# ۲) تنظیم توکن
cp .env.example .env
# فایل .env را باز کنید و توکن خود را جایگزین your_token_here کنید

# ۳) اجرا
python3 telegram_turbo_pro_final.py
```

---

## 🎯 استفاده

1. در تلگرام به ربات `/start` بفرستید.
2. از منوی شیشه‌ای استفاده کنید:
   - **📋 کانال‌ها** → افزودن / فهرست / حذف
   - **🔧 پروکسی** → افزودن / فهرست / حذف
   - **❓ راهنما** → توضیحات
3. برای لغو هر عملیاتِ در حال انتظار، `/start` را بفرستید.

**قوانین ورودی:**
- نام کانال: ۵ تا ۳۲ کاراکتر انگلیسی، عدد یا `_`
- پروکسی: `1.2.3.4:8080` یا `http://host:8080` یا `socks5://user:pass@host:1080`

## 📁 ساختار فایل‌ها

```
telegram_turbo_pro_final.py   # ربات اصلی (v4.0)
test_bot.py                   # مجموعه‌ی تست
requirements.txt              # وابستگی‌ها
.env.example                  # نمونه‌ی متغیر محیطی
SETUP.sh                      # نصب خودکار
README.md                     # همین فایل
QUICK_START.md                # شروع سریع
CHANGELOG_v4.0.md             # تاریخچه‌ی تغییرات
```

داده‌ها در `data.db` (SQLite) و لاگ‌ها در `logs/` ذخیره می‌شوند؛ هر دو به‌صورت
خودکار ساخته می‌شوند و در `.gitignore` قرار دارند.
