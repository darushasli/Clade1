# 🚀 ربات سین‌زن TURBO Pro

ربات تلگرامی قدرتمند برای افزایش سین (View) کانال‌های تلگرام با قابلیت‌های پیشرفته و استخراج خودکار پروکسی.

## ✨ ویژگی‌های اصلی

- ⚡ **سرعت فوق‌العاده**: 1000+ سین در ثانیه
- 🔄 **پردازش موازی**: 150 درخواست همزمان
- 🌐 **استخراج هوشمند پروکسی**: از وب‌چنل‌های تلگرام
- 🧪 **تست خودکار پروکسی**: بررسی و حذف خودکار پروکسی‌های نامعتبر
- 🛡️ **پایداری کامل**: Thread-safe و Async
- 📊 **مدیریت آسان**: رابط کاربری ساده و شهودی
- 🔐 **امنیت**: تنظیمات محفوظ و لاگ‌های مفصل

## 📋 نیازمندی‌ها

- Python 3.8+
- pip

## ⚡ نصب سریع

### 1. نصب کتابخانه‌ها

```bash
pip install -r requirements.txt
```

### 2. تنظیم توکن بات

```bash
cp .env.example .env
```

سپس فایل `.env` را ویرایش کنید و توکن بات خود را اضافه کنید:

```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### 3. اجرای بات

```bash
python telegram_turbo_pro_final.py
```

## 🧪 تست

```bash
python test_bot.py
```

## 📖 راهنمای استفاده

دستور `/start` را ارسال کنید تا منوی اصلی ظاهر شود.

### 🎯 عملیات اصلی

#### ➕ افزودن کانال
کانالی برای سین‌زنی خودکار اضافه کنید

#### 📋 لیست کانال‌ها
تمام کانال‌های اضافه شده را مشاهده کنید

#### 🌐 استخراج پروکسی (جدید!)
پروکسی‌ها را خودکار از وب‌چنل‌های تلگرام استخراج کنید

#### 🧪 تست پروکسی (جدید!)
تمام پروکسی‌ها را تست کنید و پروکسی‌های نامعتبر را حذف کنید

## 📊 ساختار فایل‌ها

| فایل | توضیح |
|------|------|
| `telegram_turbo_pro_final.py` | کد اصلی بات (Pro Edition) |
| `test_bot.py` | تست جامع |
| `requirements.txt` | کتابخانه‌های مورد نیاز |
| `.env` | توکن و تنظیمات حساس |
| `config.json` | تنظیمات ذخیره شده |
| `logs/` | فایل‌های لاگ |
