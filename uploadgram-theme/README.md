# تم وردپرس آپلودگرام (UploadGram)

تم اختصاصی فروشگاه خدمات دیجیتال آپلودگرام — فروش ممبر، اکانت پرمیوم و شماره مجازی.
طراحی دارک، راست‌به‌چپ (RTL)، فارسی، ریسپانسیو و آماده اتصال به ووکامرس.

---

## ✨ ویژگی‌ها

- **دارک تم حرفه‌ای** همرنگ سایت نمونه (سبز نعناعی `#16C79A` + آبی + طلایی)
- **۴ صفحه اصلی آماده**: خانه، خرید ممبر، اکانت پرمیوم، شماره مجازی
- **راست‌چین کامل** با فونت وزیرمتن + Inter برای اعداد
- **ریسپانسیو** روی موبایل، تبلت و دسکتاپ
- **تب‌های پلتفرم** (تلگرام/اینستاگرام/یوتیوب/سان‌کلو/اسپاتیفای) با جاوااسکریپت
- **آکاردئون سوالات متداول**، فیلتر اکانت‌ها، جستجوی کشور
- **راه‌اندازی خودکار**: با فعال‌سازی تم، صفحات و منو خودکار ساخته می‌شوند
- **آماده ووکامرس** با استایل هماهنگ فروشگاه، سبد خرید و تسویه‌حساب
- تمام **آیکن‌ها، لوگو، بنر و آیکن‌های سفارشی** از فایل خودتان استفاده شده

---

## 📦 نصب (روش ۱ — پیشنهادی، از پنل وردپرس)

۱. کل پوشه `uploadgram-theme` را در قالب فایل ZIP فشرده کنید
   (یا از فایل `uploadgram-theme.zip` که برایتان ارسال شده استفاده کنید).

۲. وارد پیشخوان وردپرس شوید:
   **نمایش (Appearance) ← پوسته‌ها (Themes) ← افزودن پوسته ← بارگذاری پوسته**

۳. فایل ZIP را انتخاب و **نصب** کنید، سپس **فعال** کنید.

۴. همین که تم فعال شد، به‌صورت **خودکار**:
   - صفحات «خانه»، «خرید ممبر»، «اکانت پرمیوم»، «شماره مجازی» و «تماس با ما» ساخته می‌شوند
   - قالب صحیح به هر صفحه اختصاص داده می‌شود
   - صفحه «خانه» به‌عنوان صفحه اول سایت تنظیم می‌شود
   - منوی اصلی ساخته و به جایگاه هدر متصل می‌شود

۵. تمام! به آدرس سایت بروید تا نتیجه را ببینید.

---

## 📦 نصب (روش ۲ — دستی، از طریق FTP/هاست)

۱. پوشه `uploadgram-theme` را کامل در مسیر زیر آپلود کنید:
   ```
   wp-content/themes/uploadgram-theme/
   ```

۲. از پیشخوان: **نمایش ← پوسته‌ها** و روی **UploadGram** کلیک روی **فعال کردن**.

۳. مراحل خودکار بالا اجرا می‌شوند.

## ⚙️ تنظیمات پس از نصب

### اگر صفحات خودکار ساخته نشدند
به **تنظیمات ← خواندن (Settings → Reading)** بروید و «صفحه اول نمایش دهد» را روی
صفحه‌ی **خانه** تنظیم کنید.

### منو
اگر منو نمایش داده نشد: **نمایش ← فهرست‌ها (Menus)**، منوی «منوی اصلی» را
به جایگاه **منوی اصلی (Primary)** اختصاص دهید.

### پیوندهای یکتا (مهم)
یک‌بار به **تنظیمات ← پیوندهای یکتا (Permalinks)** بروید و **ذخیره** کنید
تا آدرس صفحات درست کار کنند.

### لوگو
از **سفارشی‌سازی (Customize) ← هویت سایت** می‌توانید لوگوی خودتان را جایگزین کنید
(لوگوی پیش‌فرض از `assets/brand/` بارگذاری می‌شود).

├── screenshot.png            ← تصویر پیش‌نمایش تم
├── inc/
│   └── setup-pages.php       ← ساخت خودکار صفحات و منو
└── assets/

    ├── css/woocommerce.css   ← استایل فروشگاه
    ├── js/main.js            ← تب، آکاردئون، فیلتر، جستجو
    ├── brand/                ← لوگو

    ├── ai/                   ← آیکن‌های هوش مصنوعی
    ├── custom/               ← آیکن‌های سفارشی سه‌بعدی
    ├── hero/                 ← تصاویر هیرو
    └── ...

## 🎨 شخصی‌سازی رنگ‌ها

تمام رنگ‌ها به‌صورت متغیر CSS در ابتدای `assets/css/main.css` تعریف شده‌اند:

```css
:root {
  --mint:  #16C79A;   /* رنگ اصلی برند */
  --sky:   #0099dd;   /* آبی */
  --gold:  #F4B740;   /* طلایی */
  --bg:    #0b0d17;   /* پس‌زمینه */
  ...
}
```

کافیست همین مقادیر را تغییر دهید تا رنگ کل سایت عوض شود.

## 🛒 اتصال به ووکامرس (مرحله بعد)

تم کاملاً با ووکامرس سازگار است. پس از نصب افزونه ووکامرس:
- استایل فروشگاه به‌صورت خودکار هماهنگ می‌شود
- تعداد سبد خرید در هدر واقعی می‌شود
- برای تبدیل پکیج‌ها به محصولات واقعی، هر پلن را به‌عنوان یک محصول ووکامرس بسازید

> پلن‌ها و قیمت‌های فعلی به‌صورت نمونه در قالب‌ها قرار دارند. در مرحله پلاگین‌ها
> این‌ها را به محصولات ووکامرس متصل می‌کنیم.
